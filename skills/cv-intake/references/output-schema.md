# CV Markdown Schema

Use this structure when creating a new CV:

```markdown
# Candidate Name

**Target Role**  
City, Country | Phone | Email | Optional link

## Professional Profile

Two or three factual sentences tailored to the target role.

## Professional Experience

### Job Title — Employer

City, Country | Start year — End year or duration

- Responsibility or verified achievement.
- Responsibility or verified achievement.

## Education

- Qualification — Institution, City, Country | Year or approximate year

## Skills

- Relevant skill.
```

Use `##` for major sections and `###` for roles. Use `**bold**` only for meaningful emphasis such as the target role. Do not include a photo in Markdown unless the user explicitly uses the `<!-- CV_PHOTO -->` marker and selected a photo-enabled theme.
