# Interview Guide

Use this order unless the user already supplied a complete section:

1. Preferred name, optional location, phone, email, LinkedIn or portfolio if applicable. Ask for location directly and never infer it from another CV, work history, or system context.
2. Target role, industry, country, and language of the application.
3. Short professional profile: strengths supported by actual experience.
4. Work history, newest to oldest. For each role ask for employer, city/country, dates, title, daily responsibilities, tools, and measurable results only when known.
5. Education, courses, certifications, and languages.
6. Relevant skills and software.
7. Optional photo, theme, accent, and DOCX/PDF preference.

Use direct, neutral wording. Convert informal descriptions into action-oriented bullet points, but preserve the candidate's meaning. Flag gaps or contradictions for confirmation rather than guessing.
